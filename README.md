# TechTree Studies

A cybersecurity study platform built with Next.js and TypeScript.

TechTree Studies provides study notes, practice exams and progress tracking for learners preparing for certifications such as CompTIA Security+.

## Features

- **Dashboard:** View exam results, average scores, pass rates and study activity.
- **Study Notes:** Browse learning material organised by certification domain and module.
- **Practice Exams:** Answer multiple-choice questions, receive scores and review your answers.
- **Progress Tracking:** Keep track of exam attempts, performance and daily study streaks.
- **Profile Settings:** Manage your display name and avatar.
- **Responsive Layout:** Access the platform on desktop, tablet and mobile devices.

## Technology Stack

| Technology | Purpose |
|---|---|
| Next.js | Application framework |
| React | User interface |
| TypeScript | Type safety |
| Tailwind CSS | Styling |
| Lucide React | Icons |
| Sonner | Notifications |
| localStorage | Local profile and study data |
